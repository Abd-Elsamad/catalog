# SMEDO Supplements — Product Catalog

A modern and responsive **sports nutrition product catalog** built for **SMEDO Supplements**.

The website is designed to provide customers with a clean and premium browsing experience for supplements, without checkout, payments, accounts, or unnecessary e-commerce features.

## ✨ Features

* 🥤 Premium supplements product catalog
* 🔎 Instant product search
* 🗂️ Dynamic category filtering
* ↕️ Product sorting

  * Default
  * Price: Low to High
  * Price: High to Low
  * Name: A-Z
  * Name: Z-A
* 📊 Dynamic product counter
* 🖼️ Product images
* 📋 Detailed product modal
* ⌨️ ESC key support for closing the modal
* 📱 Fully responsive design
* 🌙 Premium dark sports-nutrition UI
* ✨ Subtle hover and transition effects
* ⬆️ Back-to-top button
* 📱 Mobile navigation
* ♿ Basic accessibility support
* 🚀 Lightweight and fast
* 🔗 Social media and contact links

## 🛠️ Technologies

## 🔍 Product Catalog

Product information is organized inside a JavaScript array, making the catalog easy to maintain.

Each product can contain information such as:

```javascript
{
    id: 1,
    name: "Product Name",
    price: 5600,
    image: "images/product.jpg",
    category: "Whey Protein",
    description: "Product description...",
    flavor: "",
    size: ""
}
```

This structure makes it easy to add, edit, or remove products without changing the main website structure.
